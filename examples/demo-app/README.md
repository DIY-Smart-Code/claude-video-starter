# Focus Ring

A 25-minute focus timer that lives in one HTML file.

- The ring empties as the minutes run down, so you can see how much is left at a glance.
- Three modes: Focus 25, Break 5, Long break 15.
- Counts your finished focus sessions and remembers them in the browser.
- No install, no account, no build step. Open `index.html` in a browser.

This is the demo app for step 8 of the starter: point `/brag` at this folder and it makes a launch clip for it.
